## 已完成的模型

Server 与独立 Client 共用任务内核，具备事件订阅、双向请求、请求流、主动流、插件管线、按连接调度和取消清理。队列、字节、活动任务和期限保护作为可选配置保留。

现有架构不继续扩展层级；后续只修复首版用法和交付中发现的具体问题。

## 接下来的交付工作

1. 完成有限的组合通信与重复连接清理验收，确保现有资源保护一起使用时行为正确。
2. 补齐七包元数据、许可证、变更和贡献说明；核对实际 tarball 与公开依赖版本。

4. 通过本地与远端 CI 验证后，按依赖次序发布，再从注册表干净安装验证。

完整压力矩阵、Worker、多目标流聚合、端到端流控和持久化列入后续，不与本版发布绑定。真实验证记录见[发版评估](发版评估.md)。
