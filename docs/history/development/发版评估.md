# 首版交付准备与发版评估

评估日期：2026-09-28。对象为本地工作区实现、发布配置与公开注册表信息；账号权限和 GitHub 远端交付尚待核实。

## 结论

当前通信模型已形成可验证闭环，首版工作转向修复剩余正确性问题、说明现有 API 和完成 GitHub/npm 交付。保持七包结构及已实现能力，不继续增加协议、调度或资源控制抽象。具体交付清单以[首版交付范围](首版交付范围.md)为准。

本次重构尚未发布，包配置也未达到直接发布条件。完成下列有限验收与发布准备后，可按明确的支持范围交付首个完整版本；不将先发预发布版本设为必经步骤。行为测试通过不等于所有输入和负载都稳定，真实限制应写入文档，而不应全部转化为首版新增功能。

## 首版范围

- 通知订阅、双向单结果请求、流式请求、主动流及既有 requestAll 结果收集。
- 共享任务生命周期：结果关联、超时、取消、连接隔离、断连清理和错误可观察。
- 独立通用 Client，支持浏览器原生 WebSocket 和 Node ws；配套协议通过显式配置启用。
- 保留插件管线、按连接调度及已有可选资源限额；常规使用无需逐项配置高级选项。
- 可安装的七个包、使用与维护文档、迁移说明、示例和可重复运行的 CI 检查。

现有 route/handle 保留兼容入口，新代码使用文档中的四种通信意图。不为首版重新命名整套 API，也不要求新增完整事件类型映射。

## 首版保留的真实边界

- 已实现全局/每 Peer 等待队列条数、传输字节额度及登记中的活动任务上限。默认请求额度继续生效，其他未配置维度仍无限额；不承诺全部 JS 堆内存受控。
- 已实现入站执行期限与流空闲期限，超时结算对应逻辑任务。忽略 signal 的用户函数仍可能运行，真实业务并发由应用通过合作取消或执行池管理。
- 当前验证基线为 Node 22 和真实 Edge 原生 WebSocket；浏览器 Worker 尚未单独验证。CI 配置存在不代表远端已执行；验证脚本缺少浏览器时会明确跳过实际握手。
- 不提供多目标流聚合、消息持久化、断点续传和自动业务重放。第三方协议须自行声明并实现请求/流能力，不能由 Client 猜测。

完整跨平台/多浏览器/Worker 矩阵、长时间大规模压力与重连风暴、消费对象字节估算、端到端确认窗口、更复杂的事件泛型映射属于后续工作，不作为首版交付阻断。有限验收中已经发现的资源泄漏、跨连接串扰或重复结算仍须修复。

## 交付顺序

发版文档门槛：确定发版前，清理根 README、七包 README、使用/迁移/架构文档中的 Alpha、内测、发布准备阶段等临时定位，保留真实能力边界、兼容要求及版本迁移信息。历史阶段记录归档，不混入当前使用文档；同时检查 tarball 内 README。此项不代表现在改版本号或提前发布。

1. 固定上述首版范围，补有限组合/重复连接清理回归，仅修复现有模型的正确性问题。
2. 完成版本、七包依赖、许可证/元数据、迁移与 API 文档及 GitHub 交付文件。
3. 对最终源码执行格式、严格类型、行为测试、七包仓库外安装、README 示例及真实浏览器验证；推送后确认远端 CI。
4. 核实发布权限并确认发布清单，按基础包 → runtime-core → server/client 发布；验证公开注册表安装及消费示例。
