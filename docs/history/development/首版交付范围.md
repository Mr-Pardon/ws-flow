## 本版包含

| 用户意图 | 主要 API |
| --- | --- |
| 发送与筛选普通事件 | send / emit / subscribe / on |
| 发起请求并自动关联一个结果 | request / handleRequest |
| 请求连续结果 | requestStream / handleStream |
| 主动推送连续数据 | stream / onStream |

保留 Server 的 Session、房间与目标筛选，保留插件管线和调度层；Client 可独立使用通用协议，也可与配套 Server 互通。已有资源限制和期限能力继续保留为可选配置，入门示例不要求理解全部选项。

首版不再新增架构层或为了统一命名破坏已有入口。原有 route/handle 的兼容行为与新请求 API 的区别在文档中说明；问题修复优先局部完成。

## 包与版本安排

沿用七包结构。先发布 consumer、envelope、pipeline、scheduler，再发布 runtime-core，最后发布 server/client。基础包是可独立维护的依赖；不为本版额外增加 bundler、合包入口或发布管理框架。

2026-09-28 公开注册表查询：Client latest 为 1.1.2，其余六包返回 404。404 不证明名称或 scope 发布权限。Client 重构使用 2.x 兼容边界；建议本次 Client 2.0.0，Server 与基础包 1.0.0，后续按各包兼容变化维护版本。最终包名与版本需在发布归属确认后写入清单。

使用 pnpm pack/publish 处理 workspace 依赖；包验证需确认产物引用实际包版本。仓库外 tarball overrides 验证构建正确性，正式发布后再从注册表安装，确认依赖确实可获取。

## 支持与验收边界

首版 Node 验证基线为 22，使用 ESM。浏览器显式使用 /browser，已在真实 Edge 验证原生 WebSocket。其他环境按标准接口设计，但未验证的旧版 Node、其他浏览器及 Worker 不作已验证承诺。

验收聚焦：核心用法可运行，明确异常可捕获，任务结算一次，断连清理本库持有的资源，新连接不接收旧任务。用户代码仍需协作响应 signal；逻辑任务数量不等于业务执行并发或堆内存上限。
