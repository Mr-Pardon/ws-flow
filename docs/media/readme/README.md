# README 视觉资源

根目录 README 使用此目录的 SVG 原稿。所有图形均为可编辑路径，不依赖外部字体文件、图片服务或脚本。

| 文件 | 用途 |
| --- | --- |
| `mark.svg` | Woven Flow 双色标志，透明背景 |
| `mark-light.svg` | 标志的单色反白备选 |
| `banner.svg` | 桌面首屏，1200 × 440 |
| `banner-mobile.svg` | 手机首屏，640 × 620 |
| `architecture.svg` | 桌面架构图，1200 × 520 |
| `architecture-mobile.svg` | 手机架构图，640 × 890 |

主标志保留青绿色 `#2c675d`、深松绿色 `#14342c` 与暖白底色 `#f6f5f1` 的搭配。横幅中的深色通信示意使用薄荷色辅助线，与双色标志区域区分。

`mark.svg` 是标志轮廓的维护源。两张横幅内嵌同一组路径，文档站图标位于 `../../manual/public/flow-mark.svg`；修改轮廓时同步这三处，保持长宽比例和交织处的留白。

README 通过 `<picture>` 在 640px 断点切换横幅和架构图。修改后检查桌面、手机、深浅主题，以及文档站图标的 16px / 32px 显示效果。
