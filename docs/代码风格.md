# 代码风格与维护验证

保留简洁风格：两空格缩进、单引号、无末尾分号、无尾逗号。目标行宽 90 字符，长参数、类型、对象、条件按语法结构换行；长字符串/路径并非硬切为 90 字符。

类的方法、构造器、访问器之间留一个空行；顶层类、函数、接口、类型声明间留空行。复杂流程按业务阶段手动分段，格式工具不会替开发者判断所有逻辑分组。

```sh
pnpm run format
pnpm run format:check
```

配置在 .prettierrc.json。scripts/format.mjs 使用 Prettier 处理换行和缩进，再按 TypeScript 语法节点补成员间距，避免使用正则匹配大括号误伤字符串/注释。检查模式不写文件。

范围为 packages 内源码、scripts、tests、examples 的 ts/mjs，跳过 node_modules/dist。legacy 历史源码、生成产物和旧文档不参与批量改写。行尾统一 LF。

提交前运行格式检查、严格类型、行为测试；涉及包出口/声明/依赖时运行 verify-packages，涉及浏览器环境时运行 verify-browser。CI 已加入 format:check。
